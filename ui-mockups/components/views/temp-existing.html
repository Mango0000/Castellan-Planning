Why does Prisma throw P2002 when I seed with createMany?
Codex · scratch P2002 is a unique-constraint violation. With createMany Postgres aborts the whole batch, so one duplicate row fails all of them. Use skipDuplicates or upsert. 
await db.user.createMany({
  data: rows,
  skipDuplicates: true,
});
