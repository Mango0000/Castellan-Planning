04 — Codex Integration

The first agent integration uses OpenAI Codex App Server. It provides structured communication with the agent, thread management, streaming events and approval workflows.

Task lifecycle

  1. Create or select project.
  2. Prepare persistent workspace.
  3. Start or resume Codex session.
  4. Send task through backend.
  5. Stream execution events.
  6. Display progress and changes.
  7. Inspect results and continue.

Visible agent information

  • Current activity
  • Tool calls
  • Terminal commands and output
  • File changes
  • Approval requests
  • Test results
  • Session state

06 — Extensible Agent Adapter

The application must never directly depend on Codex-specific logic. Every provider implements a shared interface. 

interface AgentAdapter {
  createSession(config): Promise<Session>;

  sendMessage(sessionId, message): Promise<void>;

  streamEvents(sessionId): AsyncIterable<AgentEvent>;

  stopSession(sessionId): Promise<void>;

  getStatus(sessionId): Promise<AgentStatus>;

  getCapabilities(): AgentCapabilities;
}

Provider-specific features such as approvals, file operations, session recovery and terminal access should be exposed through capability declarations rather than assumed to be identical.

Separate execution machine

Recommended: 8–16 GB RAM
  • Codex App Server
  • Docker workspaces
  • Project execution
  • Terminals
  • Persistent storage

Agent execution should be isolated from the public-facing control plane. Use restricted permissions, separate workspaces and secure credential handling.

10 — Product Principles

01. Codex-first, not Codex-only.
Build the initial integration deeply without coupling the platform to it.

02. Platform-owned projects.
Projects, files, Git repositories and task history remain independent of agent providers.

03. Secure execution.
Run coding agents in isolated environments with controlled permissions.

04. Real-time transparency.
Show actual execution events instead of artificial progress indicators.

05. Replaceable engines.
Add new agents without redesigning the frontend or project system.

THE PRODUCT VISION

A development environment without agent lock-in.

A self-hosted AI coding workspace that allows users to manage projects, run Codex, monitor its work in real time and eventually switch between different AI coding agents without changing their development environment.
